# 家具产业集群协作资料服务

维护园区、企业、应急联系人和可共享资源目录，为跨企业协作提供隔离的主体与审计基础，并提供面向同一园区多家企业同时出现废气治理告警时的**集群联防协同服务**。

系统采用 Python 标准库和 SQLite，可在单个 Linux 进程中运行。现有能力包括操作者与角色登记、场所台账、领域资料记录、请求幂等校验、哈希串联审计、版本化联防预案、脱敏信号归并、唯一指挥链、带版本备用能力协同和轻量 HTTP/JSON 接口。领域资料类别为：cluster_profile、member_enterprise、emergency_contact、resource_catalog。所有写操作都在事务中完成，同一请求编号携带相同内容时返回原结果，内容发生变化时返回业务冲突。

## 集群联防协同

当同一集群（`group_key`）内多家家具企业对同一类风险信号（`signal_type`）同时告警时，街道需要判断属于单厂故障、共用供应异常还是区域性风险，且不能把一家企业的敏感生产数据暴露给其他企业。服务按以下规则协同：

- **脱敏信号归入事件**：企业只上报脱敏信号（严重度、信号类型、去重键、上报场所），服务把同 `(集群, 信号类型)` 的信号归入同一进行中事件；同一 `dedup_key` 的重复信号合并为一条信号、多个来源，来源携带上报次数。
- **版本化预案**：预案（级别、牵头人角色、响应时限、升级规则、附录窗口）按版本发布，事件在打开时绑定确定版本；新版本激活不影响既有事件的判定依据。
- **自动升级与牵头人**：达到“不同企业数 + 最高严重度”规则时自动升级并按级别刷新响应时限；牵头人由管理员按预案级别要求的角色指定，带乐观版本号；升级到需要更高角色的级别后，原牵头人必须经管理员重新指定才能继续指挥，保证指挥链唯一。
- **备用能力协同**：企业声明可共享的备用设备/技术人员数量，指挥人员带版本批量预占、确认或释放；预占按“全部预检通过后写入”保证原子性，任一能力不足或版本过期整体回滚，绝不留下不平衡的资源扣减。
- **撤回只影响未确认量**：企业调减共享量时，已确认量受保护（不得低于已确认量），只有尚未确认的预占按先预占先驱逐释放。
- **按角色裁剪字段**：参与企业可看到自身责任、自有预占和聚合态势（其他企业来源折叠为匿名数量与严重度分布，能力目录对他企匿名）；监管人员（admin/auditor）和现任牵头人可追溯完整来源与全部预占；非参与企业无权查看。
- **终态与附录**：事件关闭后、绑定预案的附录窗口内到达的信号进入 `appendix`，合并来源但不重开终态；窗口之后的信号视为新一轮风险并开立新事件。
- **重启与并发**：所有状态、指挥链、幂等回执与审计链持久化在 SQLite；写事务使用 `BEGIN IMMEDIATE` 串行化，并发预占、确认和指挥指定只有一个胜出者，失败整体回滚。

## 主要接口

- `POST /plans`：发布新版本预案（级别、规则、默认级别、覆盖集群、附录窗口）。
- `GET /plans?plan_id=&version=`：读取预案版本。
- `POST /signals`：上报脱敏风险信号（自动开事件、合并、升级或归入附录）。
- `POST /signals/withdraw`：企业撤回自己的一条信号来源。
- `GET /incidents`、`GET /incidents/{id}`：事件列表与按角色裁剪的事件视图。
- `POST /incidents/{id}/commander`：指定/更换牵头人（带 `expected_version`）。
- `POST /incidents/{id}/close`：现任牵头人关闭事件。
- `POST /incidents/{id}/reservations|confirmations|releases`：批量预占/确认/释放。
- `GET /incidents/{id}/command-chain`：指挥链历史（受同一参与边界约束）。
- `POST /capacities`、`POST /capacities/{id}/update`、`GET /capacities`：声明、调整/撤回共享能力与目录查询。

## 目录

- `src/cluster_response_core/`：领域模型、SQLite 存储、权限服务、审计链、联防协同、HTTP 路由和离线验收；
- `tests/`：核心规则、事务边界、并发裁决、接口路由和端到端验收测试。

## 离线验收

```bash
PYTHONPATH=src python3 -m cluster_response_core.acceptance
```

命令会在临时 SQLite 数据库中登记操作者、场所和领域资料，并演练多厂告警归并升级、指挥链指定、备用能力原子预占确认、字段隔离和关闭后附录，核对幂等回执与审计链，成功时输出一行 `status` 为 `ok` 的 JSON 并以退出码 `0` 结束。

## HTTP 服务

```bash
PYTHONPATH=src python3 -m cluster_response_core.api --database cluster_response_core.sqlite3 --host 127.0.0.1 --port 8080
```

健康检查使用 `GET /health`。业务写入接口通过 `X-Actor-Id` 标识操作者，支持操作者、场所、领域资料登记、联防预案、信号、指挥链、备用能力协同，以及审计事件查询。服务重启后，SQLite 中的业务状态、指挥链、幂等回执和审计链继续保留。
